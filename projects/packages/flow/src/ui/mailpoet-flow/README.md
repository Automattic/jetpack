# MailPoet flow tree (reference copy)

Unmodified copy of the automation flow tree from [MailPoet](https://github.com/mailpoet/mailpoet):

- Components: [`assets/js/src/automation/editor/components/automation`](https://github.com/mailpoet/mailpoet/tree/trunk/mailpoet/assets/js/src/automation/editor/components/automation)
- Styles: [`assets/css/src/components-automation-editor`](https://github.com/mailpoet/mailpoet/tree/trunk/mailpoet/assets/css/src/components-automation-editor)

It is not built or imported yet: it depends on MailPoet's data store, `wp-js-hooks` and Composite components, so it is excluded from type checking and linting. The flow editor uses its own simplified tree; this folder is here so the two can later be merged into a shared package.
