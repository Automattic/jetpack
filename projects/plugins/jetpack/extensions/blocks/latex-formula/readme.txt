A WordPress block for writing and displaying LaTeX formulas. Edit your formulas in real time with a live rendering preview, and save the result with a "Done" button.

== Description ==

The Latex Formula block allows you to easily include mathematical formulas and equations in your posts and pages using standard LaTeX syntax. As you type the LaTeX code, a live preview updates below the editor, displaying the rendered formula. Once you're satisfied with the formula, click the "Done" button to save and display the properly formatted output.

This block is ideal for educators, scientists, mathematicians, or any site that wants to show mathematical notation or equations with proper formatting.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/latex-formula` directory, or install the plugin through the WordPress plugins screen directly.
1. Activate the plugin through the 'Plugins' screen in WordPress

== Frequently Asked Questions ==

= Can I edit the formula after saving? =

Yes. Just click on the block to edit your LaTeX code and update the formula.

= What LaTeX syntax is supported? =

The block uses KaTeX, which supports a substantial subset of LaTeX math syntax for most use cases.
