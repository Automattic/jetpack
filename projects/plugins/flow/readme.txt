Connect Jetpack, MailPoet, CRM and WooCommerce with if-this-then-that flows.

== Description ==

Describe what should happen, or drag triggers and actions together. Flow can email any user on your site, send webhooks, add contacts to MailPoet, Hostinger Reach or Jetpack CRM, create Google Sheets and more.

== Installation ==

1. Install the plugin through the WordPress plugins screen.
2. Activate the plugin.
3. Open the Flow menu to build your first flow.
