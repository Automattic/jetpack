# Line Chart

Line Charts visualize data trends over time or other continuous variables, connecting data points with smooth or linear lines. They excel at showing patterns, trends, and relationships in time-series data.

<Canvas of={ LineChartStories.Default } />

## Overview

The Line Chart component provides a flexible, accessible, and highly customizable solution for displaying temporal data. Built on `@visx/xychart`, it supports multiple data series, various curve types, interactive tooltips, legends, and compound components for advanced features like annotations:

<Source
	language="jsx"
	code={ `import { LineChart } from '@automattic/charts';

	<LineChart data={ data }>
		{/* Optional child components for advanced features */}
		<LineChart.AnnotationsOverlay>
			<LineChart.Annotation
				datum={ { date: new Date('2024-01-01'), value: 100 } }
				title="Product Launch"
			/>
		</LineChart.AnnotationsOverlay>
	</LineChart>` }
/>

## Basic Usage

### Simple Line Chart

The simplest line chart requires only a `data` prop with time-series data:

<Canvas of={ LineChartStories.SingleSeries } />

<Source
	language="jsx"
	code={ `<LineChart
		data={[
			{
				label: 'Temperature',
				data: [
					{ date: new Date('2024-01-01'), value: 20 },
					{ date: new Date('2024-01-02'), value: 25 },
					{ date: new Date('2024-01-03'), value: 18 },
				],
				options: {}
			}
		]}
	/>` }
/>

### Required Props

- **`data`**: Array of series data, each containing `label`, `data` array, and optional `options`

### Optional Props

- **`width`**: Chart width in pixels (responsive by default)
- **`height`**: Chart height in pixels (responsive by default)
- **`withTooltips`**: Enable interactive tooltips (`true` by default)
- **`showLegend`**: Display chart legend (`false` by default)
- **`curveType`**: Line curve style (`'smooth'`, `'linear'`, `'monotone'`)
- **`withGradientFill`**: Fill area under lines with gradient (`false` by default)
- **`margin`**: Custom chart margins
- **`options`**: Advanced axis and scale configuration

## Curve Types

### Linear Curves

Connect data points with straight lines for precise, unsmoothed visualization:

<Canvas of={ LineChartStories.CurveTypes } />

### Smooth Curves (Catmull-Rom)

Create flowing curves that pass through all data points using Catmull-Rom spline interpolation:

<Source
	language="jsx"
	code={ `<LineChart
		data={data}
		curveType="smooth"
	/>` }
/>

### Monotone X Curves

Prevent overshooting while maintaining smoothness, ideal for data with sharp changes:

<Source
	language="jsx"
	code={ `<LineChart
		data={data}
		curveType="monotone"
	/>` }
/>

**When to use each type:**
- **Linear**: Raw data visualization, technical charts, precise measurements
- **Smooth**: Aesthetic presentations, trend visualization, marketing materials
- **Monotone**: Financial data, scientific measurements where overshooting would be misleading

## API Reference

### LineChart

Main chart component with responsive behavior by default.

**Props:**

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `data` | `SeriesData[]` | - | **Required.** Array of data series to display |
| `width` | `number` | responsive | Chart width in pixels |
| `height` | `number` | responsive | Chart height in pixels |
| `curveType` | `'smooth' \| 'linear' \| 'monotone'` | `'smooth'` | Line curve interpolation type |
| `withGradientFill` | `boolean` | `false` | Fill area under lines with gradient |
| `withTooltips` | `boolean` | `true` | Enable interactive tooltips |
| `withTooltipCrosshairs` | `{ showVertical?: boolean; showHorizontal?: boolean }` | - | Show crosshair guides with tooltips |
| `showLegend` | `boolean` | `false` | Display chart legend |
| `legendOrientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Legend layout orientation |
| `legendAlignmentHorizontal` | `'left' \| 'center' \| 'right'` | `'center'` | Horizontal legend alignment |
| `legendAlignmentVertical` | `'top' \| 'bottom'` | `'bottom'` | Vertical legend alignment |
| `legendShape` | `LegendShape` | `'line'` | Shape used in legend markers |
| `withStartGlyphs` | `boolean` | `false` | Show markers at the first data point of each series |
| `withLegendGlyph` | `boolean` | `false` | Use custom glyphs in legend |
| `renderGlyph` | `(props: GlyphProps) => ReactNode` | - | Custom glyph render function |
| `glyphStyle` | `SVGProps<SVGCircleElement>` | `{}` | Styling for chart glyphs |
| `renderTooltip` | `(params: RenderTooltipParams) => ReactNode` | - | Custom tooltip render function |
| `margin` | `{ top?: number; right?: number; bottom?: number; left?: number }` | calculated | Chart margins |
| `options` | `ChartOptions` | `{}` | Advanced axis and scale configuration |
| `onPointerDown` | `(event: EventHandlerParams) => void` | - | Pointer down event handler |
| `onPointerUp` | `(event: EventHandlerParams) => void` | - | Pointer up event handler |
| `onPointerMove` | `(event: EventHandlerParams) => void` | - | Pointer move event handler |
| `onPointerOut` | `(event: PointerEvent) => void` | - | Pointer out event handler |
| `children` | `ReactNode` | - | Child components (e.g., annotations) |

## Performance Considerations

### Optimization Tips

- **Data size**: Charts perform well with hundreds of data points; consider data aggregation for thousands of points
- **Animation**: Animations have been removed for better performance
- **Re-renders**: Use stable references for `data`, `options`, and callback props to prevent unnecessary re-renders
- **Memory usage**: Large datasets benefit from virtualization or data sampling techniques

### Best Practices

- Prefer `Date` objects over `dateString` for better performance
- Use `curveType="linear"` for large datasets to reduce computation
- Implement data loading states for async data fetching
- Consider chart alternatives (like sparklines) for dense data displays
