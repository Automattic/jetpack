# Pie Chart

Pie Charts visualize proportional data as circular segments, making it easy to understand parts of a whole. They excel at showing percentage breakdowns and comparative relationships between categories.

<Canvas of={ PieChartStories.Default } />

## Overview

The Pie Chart component provides a flexible, accessible, and highly customizable solution for displaying proportional data. Built on `@visx/shape`, it supports interactive tooltips, legends, and customizable styling with gap control, corner rounding, and thickness adjustment:

<Source
	language="jsx"
	code={ `import { PieChart } from '@automattic/charts';

	<PieChart
		data={ data }
		withTooltips={ true }
		showLegend={ true }
	/>` }
/>

## Basic Usage

### Simple Pie Chart

The simplest pie chart requires only a `data` prop with percentage-based data:

<Canvas of={ PieChartStories.Default } />

<Source
	language="jsx"
	code={ `<PieChart
		size={ 400 }
		data={[
			{ label: 'MacOS', value: 30000, percentage: 23 },
			{ label: 'Linux', value: 22000, percentage: 17 },
			{ label: 'Windows', value: 80000, percentage: 60 },
		]}
	/>` }
/>

### Required Props

- **`data`**: Array of `DataPointPercentage` objects containing label, value, and percentage
- **`size`**: Diameter of the chart in pixels (when not using responsive mode)

### Optional Props

- **`padding`** (default: `20`): Padding around the chart in pixels
- **`withTooltips`** (default: `false`): Enables interactive tooltips on hover
- **`showLegend`** (default: `false`): Shows a legend for the chart data
- **`gapScale`** (default: `0`): Scale of gaps between segments (0-1)
- **`cornerScale`** (default: `0`): Scale of corner rounding for segments (0-1)

Adjust `thickness` to create various chart styles:

## API Reference

### PieChart

Main component for rendering pie and donut charts.

**Props:**

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `data` | `DataPointPercentage[]` | - | **Required.** Array of data objects with label, value, and percentage |
| `size` | `number` | - | Diameter of the chart in pixels (omit for responsive behavior) |
| `padding` | `number` | `20` | Padding around the chart in pixels |
| `gapScale` | `number` | `0` | Scale of gaps between segments (0-1) |
| `cornerScale` | `number` | `0` | Scale of corner rounding for segments (0-1) |
| `withTooltips` | `boolean` | `false` | Enable interactive tooltips on hover |
| `showLegend` | `boolean` | `false` | Display chart legend |
| `legendOrientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Legend layout direction |
| `legendAlignmentHorizontal` | `'left' \| 'center' \| 'right'` | `'center'` | Horizontal legend alignment |
| `legendAlignmentVertical` | `'top' \| 'bottom'` | `'bottom'` | Vertical legend position |
| `legendShape` | `LegendShape` | `'circle'` | Shape of legend markers |
| `className` | `string` | - | Additional CSS class names |
| `chartId` | `string` | - | Custom chart identifier for accessibility |
| `maxWidth` | `number` | - | Maximum width for responsive charts |
| `aspectRatio` | `number` | `1` | Aspect ratio for responsive charts |
| `resizeDebounceTime` | `number` | `100` | Debounce time for resize events (ms) |

### DataPointPercentage Type

```typescript
type DataPointPercentage = {
	/** Label for the data point */
	label: string;
	/** Numerical value */
	value: number;
	/** Formatted value for display */
	valueDisplay?: string;
	/** Percentage value (must sum to 100 across all data points) */
	percentage: number;
	/** Optional custom color override */
	color?: string;
};
```

## Migration

### From Legacy Chart Components

If migrating from other chart libraries or legacy implementations:

<Source
	language="jsx"
	code={ `// Legacy approach (example)
	<OldPieChart
		data={ data }
		width={ 400 }
		height={ 400 }
		showTooltip={ true }
	/>

	// New @automattic/charts approach
	<PieChart
		size={ 400 }
		data={ data }
		withTooltips={ true }
	/>` }
/>

### Breaking Changes

- **Size prop**: Use single `size` prop instead of separate `width`/`height`
- **Data format**: Requires `percentage` field in addition to `value`
- **Theme integration**: Colors now come from theme by default
- **Tooltip prop**: Renamed from `showTooltip` to `withTooltips`

### Data Format Migration

Ensure your data includes the required `percentage` field:

<Source
	language="jsx"
	code={ `// Old format
	const oldData = [
		{ label: 'A', value: 30 },
		{ label: 'B', value: 70 },
	];

	// New format (percentages must sum to 100)
	const newData = [
		{ label: 'A', value: 30, percentage: 30 },
		{ label: 'B', value: 70, percentage: 70 },
	];` }
/>
