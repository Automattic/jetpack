# Donut Chart

Donut Charts are circular charts with a hollow center, perfect for displaying proportional data while providing space for additional content or summary information. They are essentially pie charts with customizable thickness and center content.

<Canvas of={ DonutStories.Default } />

## Overview

The Donut Chart is created using the `PieChart` component with a `thickness` value less than 1. This creates a hollow center that can be used to display totals, titles, or other contextual information:

<Source
	language="jsx"
	code={ `import { PieChart } from '@automattic/charts';
	import { Group } from '@visx/group';
	import { Text } from '@visx/text';

	<PieChart
		thickness={ 0.5 }
		data={ data }
	>
		<Group>
			<Text textAnchor="middle" verticalAnchor="middle">
				Center Content
			</Text>
		</Group>
	</PieChart>` }
/>

## Basic Usage

### Simple Donut Chart

Create a donut chart by setting the `thickness` prop to a value between 0 and 1:

<Canvas of={ DonutStories.Default } />

<Source
	language="jsx"
	code={ `<PieChart
		size={ 400 }
		thickness={ 0.4 }
		data={[
			{ label: 'Active Users', value: 65000, percentage: 65 },
			{ label: 'Inactive Users', value: 35000, percentage: 35 },
		]}
	>
		<Group>
			<Text textAnchor="middle" verticalAnchor="middle" fontSize={ 24 }>
				User Activity
			</Text>
			<Text textAnchor="middle" verticalAnchor="middle" fontSize={ 18 } y={ 16 }>
				Total: 100K Users
			</Text>
		</Group>
	</PieChart>` }
/>

### Required Props

- **`thickness`**: Value between 0 and 1 (e.g., 0.5 for 50% thickness, creating a donut)
- **`data`**: Array of `DataPointPercentage` objects

### Key Differences from Pie Charts

- **Hollow center**: Provides space for additional content
- **Thickness control**: Adjustable ring thickness
- **Center content**: Support for custom content in the center area

## Styling and Best Practices

### Thickness Guidelines

Choose thickness values based on your content needs:

- **0.1 - 0.3**: Thin rings, good for progress indicators
- **0.4 - 0.6**: Balanced donuts, versatile for most use cases
- **0.7 - 0.9**: Thick donuts, when center content is minimal

### Center Content Guidelines

**Typography Hierarchy:**
- Use larger font sizes for primary metrics
- Smaller font sizes for labels and descriptions
- Consider font weight to establish visual hierarchy

**Content Length:**
- Keep text concise to fit comfortably in the center
- Use abbreviations for large numbers (e.g., "1.2M" instead of "1,200,000")
- Break long labels into multiple lines

**Color Usage:**
- Use theme colors for consistency
- Apply accent colors to highlight important metrics
- Ensure sufficient contrast for accessibility

### Responsive Considerations

Donut charts with center content need special attention for responsiveness:

<Source
	language="jsx"
	code={ `// Responsive text sizing
	const ResponsiveDonut = ({ size }) => {
		const fontSize = Math.max(12, size * 0.06); // Scale with chart size

		return (
			<PieChart thickness={ 0.5 } data={ data }>
				<Group>
					<Text
						textAnchor="middle"
						verticalAnchor="middle"
						fontSize={ fontSize }
					>
						{ totalValue }
					</Text>
				</Group>
			</PieChart>
		);
	};` }
/>
