# TooltipBox API Reference

Complete API documentation for the TooltipBox component.

## Props

`TooltipBox` accepts every `HTMLAttributes<HTMLDivElement>` prop, plus `unstyled`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `unstyled` | `boolean` | `false` | Drops the chart surface, scope class and dark theme, leaving a bare box |
| `role` | `AriaRole` | `'tooltip'` | The ARIA role of the box. Replaces the default |
| `className` | `string` | - | Added beside the surface classes |
| `style` | `CSSProperties` | - | Inline styles. Kept when `unstyled` is set |
| `children` | `ReactNode` | - | The tooltip content |

The component also forwards `ref` to the box element (`HTMLDivElement`).
