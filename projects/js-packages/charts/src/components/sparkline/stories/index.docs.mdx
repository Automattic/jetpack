# Sparkline Chart

A minimal, word-sized chart component designed for showing trends at a glance. Perfect for dashboard metrics and inline data visualization.

<Canvas of={ SparklineStories.Default } />

## Overview

The Sparkline component provides a clean, minimal visualization for trend data. Built on `@visx/xychart`, it supports smooth monotone curves, optional gradient fills, and handles edge cases gracefully:

<Source
	language="jsx"
	code={ `import { Sparkline } from '@automattic/charts';
import '@automattic/charts/sparkline/style.css';

<Sparkline
	data={ [10, 15, 12, 18, 22, 25, 23, 28] }
	width={ 120 }
	height={ 48 }
	color="#4CAF50"
/>` }
/>

## API Reference

For detailed information about component props and types, see the [Sparkline Chart API Reference](./?path=/docs/js-packages-charts-types-sparkline-chart-api-reference--docs).

## Basic Usage

### Simple Sparkline

The simplest sparkline requires only a `data` prop with an array of numeric values:

<Canvas of={ SparklineStories.Default } />

<Source
	language="jsx"
	code={ `<Sparkline
	data={[10, 15, 12, 18, 22, 25, 23, 28]}
	width={120}
	height={48}
	color="#4CAF50"
/>` }
/>

### Required Props

- **`data`**: Array of numeric values to plot

### Optional Props

- **`width`** (default: `100`): Width of the sparkline in pixels
- **`height`** (default: `40`): Height of the sparkline in pixels
- **`color`**: Color for the line stroke (defaults to theme color)
- **`strokeWidth`** (default: `1`): Line stroke width in pixels
- **`withGradientFill`** (default: `true`): Whether to render gradient fill beneath the line
- **`gradient`**: Custom gradient configuration (from, to, fromOpacity, toOpacity)
- **`className`**: Additional CSS class name
- **`margin`** (default: `{2,2,2,2}`): Margin around the chart

For detailed prop information and type definitions, see the [Sparkline Chart API Reference](./?path=/docs/js-packages-charts-types-sparkline-chart-api-reference--docs).

## Accessibility

Sparklines are decorative visualizations. For accessibility, ensure the parent container provides context:

<Source
	language="jsx"
	code={ `<div role="img" aria-label="Momentum trending upward, current value 28">
	<span>Momentum</span>
	<span>28</span>
	<Sparkline data={data} aria-hidden="true" />
</div>` }
/>

**Best Practices:**
- Use `role="img"` on the container
- Provide `aria-label` describing the trend and current value
- Add `aria-hidden="true"` to the sparkline itself
- Always show the actual metric value as text alongside the sparkline

## Browser Compatibility

- Firefox (latest)

- Mobile browsers (iOS Safari, Chrome Mobile)

## Performance

Sparklines are optimized for performance with:
- Memoized calculations for theme and gradient config
- Efficient data transformation
- Minimal re-renders via `useCallback` for accessors
- Small footprint (no axes, grids, or interactivity)

**Performance Tips:**
- Keep data arrays reasonably sized (under 100 points for sparklines)
- Use the responsive variant only when needed
- Reuse theme objects to prevent unnecessary recalculations
