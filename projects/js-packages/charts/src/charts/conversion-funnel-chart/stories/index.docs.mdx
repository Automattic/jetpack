# Conversion Funnel Chart

A focused conversion funnel chart component for visualizing step-by-step conversion rates with a prominent main metric display and change indicators.

<Canvas of={ ConversionFunnelChartStories.Default } />

## Overview

The ConversionFunnelChart component provides a specialized visualization for tracking user conversion through sequential steps, featuring:

- Clear funnel visualization with proportional bar heights and light backgrounds
- Main conversion rate highlighting with positive/negative change indicators
- Dynamic color theming with automatic bar background adaptation
- Complete customization control via render props
- Flexible layouts that adapt to container size
- TypeScript support with full type definitions
- Accessible design with semantic markup
- Integration with global charts theme system

<Source
	language="tsx"
	code={ `import { ConversionFunnelChart } from '@automattic/charts';
import '@automattic/charts/style.css';

	const funnelData = [
		{ id: 'sessions', label: 'Sessions', rate: 100, count: 10000 },
		{ id: 'cart', label: 'Cart', rate: 71.1, count: 7110 },
		{ id: 'checkout', label: 'Checkout', rate: 52.5, count: 5250 },
		{ id: 'purchase', label: 'Purchase', rate: 10.3, count: 1030 },
	];

	<ConversionFunnelChart
		mainRate={10.3}
		changeIndicator="+2%"
		steps={funnelData}
	/>` }
/>

## Basic Usage

### Simple Conversion Funnel

The most basic implementation requires only the main conversion rate and steps data:

<Canvas of={ ConversionFunnelChartStories.Default } />

<Source
	language="tsx"
	code={ `<ConversionFunnelChart
		mainRate={10.3}
		changeIndicator="+2%"
		steps={ecommerceFunnelData}
	/>` }
/>

### Required Props

- **`mainRate`**: The primary conversion rate to highlight (0-100)
- **`steps`**: Array of funnel steps with id, label, rate, and optional count

### Optional Props

- **`changeIndicator`**: Change indicator text (e.g., "+2%", "-1.5%")
- **`loading`**: Whether the chart is in loading state
- **`height`**: Height of the chart container. Accepts a number (pixels) or CSS string. Falls back to `style.height` if set, otherwise defaults to `"100%"`
- **`className`**: Additional CSS class name for styling
- **`chartId`**: Optional unique identifier for the chart
- **`style`**: Custom styling for the chart container

For detailed prop information and render prop types, see the [Conversion Funnel Chart API Reference](./?path=/docs/js-packages-charts-library-charts-conversion-funnel-chart-api-reference--docs).

## Customization with Render Props

### Complete Customization

Full control over component rendering with custom render functions:

<Canvas of={ ConversionFunnelChartStories.CustomRenderProps } />

<Source
	language="tsx"
	code={ `<ConversionFunnelChart
		mainRate={10.3}
		changeIndicator="+2%"
		steps={ecommerceFunnelData}
		renderMainMetric={({ mainRate, changeIndicator, className }) => (
			<div className={className} style={{
				background: 'linear-gradient(135deg, #667eea 0%, #764ba2 100%)',
				borderRadius: '12px',
				padding: '24px',
				color: 'white',
				textAlign: 'center'
			}}>
				<h3>Overall Conversion Rate</h3>
				<span style={{ fontSize: '42px', fontWeight: 'bold' }}>
					{mainRate.toFixed(1)}%
				</span>
				{changeIndicator && (
					<span style={{
						backgroundColor: changeIndicator.startsWith('+')
							? 'rgba(16, 185, 129, 0.2)'
							: 'rgba(239, 68, 68, 0.2)',
						color: changeIndicator.startsWith('+') ? '#10b981' : '#ef4444',
						padding: '6px 12px',
						borderRadius: '8px'
					}}>
						{changeIndicator}
					</span>
				)}
			</div>
		)}
		renderTooltip={({ step, content }) => (
			<div style={{ minWidth: '200px' }}>
				<div>{step.label}</div>
				{content.value && (
					<div style={{ fontSize: '18px', fontWeight: 'bold' }}>{content.value}</div>
				)}
				{content.rows?.map(row => (
					<div key={row.label}>
						{row.label}: <strong>{row.value}</strong>
					</div>
				))}
			</div>
		)}
		tooltipStyle={{
			background: 'linear-gradient(135deg, #667eea 0%, #764ba2 100%)',
			borderRadius: '12px',
			padding: '16px 20px',
			color: 'white'
		}}
	/>` }
/>

### Available Render Props

- **`renderMainMetric`**: Customize the main conversion rate display
- **`renderStepLabel`**: Customize individual step labels. Render plain text only: screen readers cannot reach it, and a link or button in it is never announced.
- **`renderStepRate`**: Customize individual step rate displays. Render plain text only, as for `renderStepLabel`.
- **`getTooltipContent`**: Set what each step's tooltip shows: a `value` beside the step's name and labeled `rows` below it. Screen readers read the tooltip as the selected step's description, without the name.
- **`renderTooltip`**: Customize the tooltip's layout. Render the `content` it receives. Screen readers read the whole rendered tooltip as the selected step's description, including the step's name if it shows one. It sits inside the dark tooltip box, so let it inherit the box colors.
- **`tooltipStyle`**: Restyle the tooltip box itself, such as its background, radius or padding. Set `color` with any background change.

## Theming Integration

Conversion Funnel Charts integrate seamlessly with the chart theming system. The default theme has neutral styling, and is automatically applied to all charts unless a custom theme is provided.

**Step colors come from the palette custom properties, not the theme object.** Set as many of the five slots as you need; an unset slot is skipped, and charts generates accessible colors beyond whatever you set:

<Source
	language="css"
	code={ `.a8c-charts-scope {
		--a8c-charts-color-series-1: #FF6B6B;
		--a8c-charts-color-series-2: #4ECDC4;
		--a8c-charts-color-series-3: #45B7D1;
	}` }
/>

Every other color works the same way — declare its catalog role. The closest declaration inside the provider tree wins, so scope the rule to one dashboard, or to `.a8c-charts-scope` to move every chart on the page:

<Source
	language="css"
	code={ `.my-dashboard {
		/* The plate behind each step: */

## Animation

The Conversion Funnel Chart component supports an optional entry animation that creates a smooth reveal effect when the chart first renders:

<Canvas of={ ConversionFunnelChartStories.Animation } />

<Source
	language="tsx"
	code={ `<ConversionFunnelChart
		mainRate={ 10.3 }
		steps={ funnelData }
		animation={ true }
	/>` }
/>

### Animation Behavior

- **Opt-in**: Animation is disabled by default and must be explicitly enabled with the `animation` prop
- **Accessibility**: Automatically respects the user's `prefers-reduced-motion` system setting - animation will not play for users who prefer reduced motion
- **Effect**: Creates a rising effect where funnel bars grow from the bottom to their full height, revealing the conversion data progressively
- **Duration**: 1000ms (1 second) with ease-out timing

**Note**: The animation plays once when the chart initially renders and does not repeat.

## Accessibility

### Keyboard Navigation

The steps form a single-select [listbox](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/) where selection follows focus, with one Tab stop. A focused step is selected and shows its tooltip, just as a clicked one does.

- **Tab**: Enters the funnel on the last focused step, else the selected step, else the first step. The next Tab leaves the funnel and clears the selection.
- **Left/Right arrows**: Move focus and the selection to the previous or next step. They are swapped in a right-to-left layout and do not wrap.
- **Home/End**: Move focus and the selection to the first or last step.
- **Escape**: Clear the selection and hide the tooltip. Focus stays on the step.
- **Enter/Space**: Select the focused step again after Escape.

### Screen Reader Support

- Set `ariaLabel` to name the chart. See [Accessible names](./?path=/docs/js-packages-charts-library-introduction--docs#accessible-names).
- **ARIA Roles**: The steps sit in a horizontal `role="listbox"` labeled "Funnel steps", and each step uses `role="option"`
- **ARIA Labels**: Each step has `aria-label` with the step name and rate, such as "Cart, 71.1%"
- **Selection State**: The selected step has `aria-selected="true"`, the others `aria-selected="false"`
- **Descriptions**: The selected step's `aria-describedby` points at its tooltip, leaving out the name line, so the default reads "7,110 items Conversion rate 71.1%". The tooltip itself is hidden from screen readers, so it is read only as the description.
- **Visible Text**: The step labels and rates above the bars are hidden from screen readers, so the listbox holds only its options. Each option's name carries the step's label and rate, and the selected option's description adds the tooltip's numbers
- **Loading States**: Loading and empty states provide appropriate text content

### Interactive Behavior

- **Click/Touch**: Clicking or tapping a step selects it and shows its tooltip at the pointer
- **Focus**: Focusing a step from the keyboard selects it and shows its tooltip, anchored at the top center of the step
- **Selection State**: Only one step can be selected at a time, with visual feedback
- **Deselection**: Moving focus out of the funnel, clicking outside it or pressing Escape clears the selection

### Focus Management

- **Roving `tabIndex`**: One step has `tabIndex={0}` and the others `tabIndex={-1}`. Dimmed (non-selected) steps stay reachable with the arrow keys.
- **Visual Focus Indicators**: The focused step shows a focus ring when focus comes from the keyboard
