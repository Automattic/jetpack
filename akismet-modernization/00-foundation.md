# Akismet UI Exploration — Plan 0: Foundation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read [README.md](./README.md) and [blackbox-notes.md](./blackbox-notes.md) first for shared context.

**Goal:** Stand up the JavaScript build pipeline, React mount, theme provider, REST/query plumbing, and Blackbox client adapter as a **new, separate admin page** (`?page=akismet-experimental`) inside the wpcom-hosted Akismet mu-plugin — so subsequent plans only have to ship feature React code.

**Architecture:** The exploration UI is a **separate admin page**, not an opt-in mode on the existing settings page. It's registered only when the wp-config constant `AKISMET_EXPERIMENTAL_UI` is `true`. The legacy `?page=akismet-key-config` page is completely untouched. The new page renders a React root wrapped in `@wordpress/theme` `ThemeProvider` + `@tanstack/react-query` `QueryClientProvider` + a thin REST adapter over `@wordpress/api-fetch`, with a Blackbox client adapter alongside it for Plans 2 and 3.

This work lands in `github.a8c.com/Automattic/wpcom` at `wp-content/mu-plugins/akismet-3.0/` (the active dev location). No public-repo backport happens from this branch.

**Tech Stack:** `@wordpress/scripts`, `@wordpress/element`, `@wordpress/admin-ui`, `@wordpress/ui` (v0.11.0+), `@wordpress/theme`, `@wordpress/components`, `@wordpress/api-fetch`, `@tanstack/react-query` (^5.90), `@automattic/jetpack-components` (`JetpackFooter`), TypeScript.

- `class.akismet-admin.php` — left exactly as-is.
- `class.akismet-rest-api.php` — left exactly as-is.
- `views/{config,stats,start,enter,connect-jp,setup,get,notice,activate,title,logo,predefined}.php` — left exactly as-is.
- The `tools.akismet.com` iframe references — left exactly as-is.

The legacy production UI continues to ship to wp.org as it does today. This work creates a parallel surface, accessible only when `AKISMET_EXPERIMENTAL_UI` is on.

  ```ts
  import apiFetch from '@wordpress/api-fetch';

  type Body = Record< string, unknown > | undefined;

  function buildPath( endpoint: string ): string {
    return `/akismet/v1/${ endpoint.replace( /^\//, '' ) }`;
  }

  export const apiClient = {
    get< T = unknown >( endpoint: string ): Promise< T > {
      return apiFetch< T >( { path: buildPath( endpoint ), method: 'GET' } );
    },
    post< T = unknown >( endpoint: string, data: Body ): Promise< T > {
      return apiFetch< T >( { path: buildPath( endpoint ), method: 'POST', data } );
    },
    put< T = unknown >( endpoint: string, data: Body ): Promise< T > {
      return apiFetch< T >( { path: buildPath( endpoint ), method: 'PUT', data } );
    },
    delete< T = unknown >( endpoint: string ): Promise< T > {
      return apiFetch< T >( { path: buildPath( endpoint ), method: 'DELETE' } );
    },
  };
  ```

**Files:**

The exploration UI is a **new admin page** — `?page=akismet-experimental` — not a mode toggle on the existing settings page. The legacy `class.akismet-admin.php` and `views/config.php` are not touched.

- [ ] **Step 1: Create `class.akismet-experimental.php`**

  ```php
  <?php
  /**
   * Akismet — experimental admin UI (internal exploration, gated by AKISMET_EXPERIMENTAL_UI).
   *
   * Not shipped to WP.org. Lives in wpcom's mu-plugins/akismet-3.0/.
   *
   * @package Akismet
   */

  defined( 'ABSPATH' ) || exit;

  class Akismet_Experimental {

      const PAGE_SLUG = 'akismet-experimental';

      // ─────────────────────────────────────────────────────────────────────────
      // Guardrail constants — see GUARDRAILS.md.
      // Production WPCOM must not define any of these. The three constants are
      // independent; turning on the UI does NOT turn on mutations or Blackbox API.
      // ─────────────────────────────────────────────────────────────────────────

      /**
       * Whether the experimental UI is enabled for this site.
       *
       * Gate: define( 'AKISMET_EXPERIMENTAL_UI', true ) in wp-config.php (a8c-internal only).
       * When false, the class file is not required at all (see akismet.php bootstrap).
       *
       * @return bool
       */
      public static function is_enabled() {
          return defined( 'AKISMET_EXPERIMENTAL_UI' ) && AKISMET_EXPERIMENTAL_UI === true;
      }

      /**
       * Whether mutating endpoints (comment approve / force-delete) are allowed.
       *
       * Default: OFF. Even when AKISMET_EXPERIMENTAL_UI is on, the prototype is
       * strictly read-only unless this constant is *also* defined. This is the
       * tripwire that prevents accidental writes to live comment data.
       *
       * Gate: define( 'AKISMET_EXPERIMENTAL_ALLOW_MUTATIONS', true ).
       *
       * @return bool
       */
      public static function allow_mutations() {
          return defined( 'AKISMET_EXPERIMENTAL_ALLOW_MUTATIONS' ) && AKISMET_EXPERIMENTAL_ALLOW_MUTATIONS === true;
      }

      /**
       * Whether the REST proxy is allowed to make real calls to blackbox-api.wp.com.
       *
       * Default: OFF. Even when an `AKISMET_BLACKBOX_API_KEY` is defined, the
       * Blackbox proxy handlers short-circuit to deterministic mocks unless this
       * constant is *also* defined. This prevents live verify / report calls
       * (which would count against Blackbox quotas + produce telemetry rows)
       * from firing during preview.
       *
       * Gate: define( 'AKISMET_EXPERIMENTAL_ALLOW_BLACKBOX_API', true ).
       *
       * @return bool
       */
      public static function allow_blackbox_api() {
          return defined( 'AKISMET_EXPERIMENTAL_ALLOW_BLACKBOX_API' ) && AKISMET_EXPERIMENTAL_ALLOW_BLACKBOX_API === true;
      }

      public static function init() {
          if ( ! self::is_enabled() ) {
              return;
          }
          add_action( 'admin_menu', array( __CLASS__, 'register_menu' ), 20 );
          add_action( 'admin_enqueue_scripts', array( __CLASS__, 'enqueue_assets' ) );
      }

      public static function register_menu() {
          if ( ! current_user_can( 'manage_options' ) ) {
              return;
          }

          $title = __( 'Akismet (Experimental)', 'akismet' );

          if ( class_exists( 'Jetpack' ) ) {
              add_submenu_page(
                  'jetpack',
                  $title,
                  $title,
                  'manage_options',
                  self::PAGE_SLUG,
                  array( __CLASS__, 'render_page' )
              );
          } else {
              add_submenu_page(
                  'options-general.php',
                  $title,
                  $title,
                  'manage_options',
                  self::PAGE_SLUG,
                  array( __CLASS__, 'render_page' )
              );
          }
      }

      public static function render_page() {
          ?>
          <div class="wrap akismet-experimental-wrap">
              <div id="akismet-experimental-app"><?php /* React mounts here. */ ?></div>
          </div>
          <?php
      }

      public static function enqueue_assets( $hook_suffix ) {
          // Only on our own page.
          $expected_hooks = array(
              'settings_page_' . self::PAGE_SLUG,
              'jetpack_page_' . self::PAGE_SLUG,
          );
          if ( ! in_array( $hook_suffix, $expected_hooks, true ) ) {
              return;
          }

          $asset_file = AKISMET__PLUGIN_DIR . 'build/index.asset.php';
          if ( ! file_exists( $asset_file ) ) {
              return;
          }
          $asset = include $asset_file;

          wp_enqueue_script(
              'akismet-experimental',
              plugins_url( 'build/index.js', __FILE__ ),
              $asset['dependencies'],
              $asset['version'],
              true
          );
          if ( file_exists( AKISMET__PLUGIN_DIR . 'build/index.css' ) ) {
              wp_enqueue_style(
                  'akismet-experimental',
                  plugins_url( 'build/index.css', __FILE__ ),
                  array(),
                  $asset['version']
              );
          }

          $blackbox = self::blackbox_client_config();

          // Whitelisted localize payload. Never include the Blackbox Bearer key here
          // (`AKISMET_BLACKBOX_API_KEY`) — see GUARDRAILS.md §"Enforcement mechanisms".
          wp_localize_script( 'akismet-experimental', 'akismetExperimental', array(
              'apiNonce'       => wp_create_nonce( 'wp_rest' ),
              'apiRoot'        => esc_url_raw( rest_url() ),
              'jetpackActive'  => class_exists( 'Jetpack' ),
              'apiKey'         => Akismet::get_api_key(),
              'pluginUrl'      => plugins_url( '', __FILE__ ),
              'pageSlug'       => self::PAGE_SLUG,
              'blackbox'       => $blackbox,         // only `enrolled`, `clientId`, `apiHost` — Bearer key stripped
              'allowMutations' => self::allow_mutations(),  // surfaces the read-only state to the UI
              // Note: we do NOT surface `allow_blackbox_api()` to the browser. That gate is
              // entirely server-side; the client never knows or cares whether the proxy is
              // hitting real Blackbox or a mock.
          ) );
      }

      /**
       * Describe whether this site is enrolled with Blackbox.
       *
       * Returns shape:
       *   array(
       *     'enrolled' => bool,        // are credentials present
       *     'clientId' => string|null, // opaque client identifier for the dashboard surfaces
       *     'apiHost'  => string,      // base for the Blackbox API
       *   );
       *
       * NOTE: the Bearer key is NEVER sent to the browser. Browser-side surfaces hit
       * server-side WP REST endpoints (added in plans 2 + 3) which forward to Blackbox
       * with the Bearer key held in PHP.
       */
      protected static function blackbox_client_config() {
          $client_id = defined( 'AKISMET_BLACKBOX_CLIENT_ID' ) ? AKISMET_BLACKBOX_CLIENT_ID : null;
          $bearer    = defined( 'AKISMET_BLACKBOX_API_KEY' ) ? AKISMET_BLACKBOX_API_KEY : '';

          return array(
              'enrolled' => ! empty( $client_id ) && ! empty( $bearer ),
              'clientId' => $client_id,
              'apiHost'  => 'https://blackbox-api.wp.com',
          );
      }
  }

  Akismet_Experimental::init();
  ```
